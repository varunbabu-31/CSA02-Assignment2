3. Q4 grade boundaries are inferred from the assignment's expected examples: S 90-100, A 80-89, B 70-79, C 60-69, D 50-59, F 0-49. Scholarship income thresholds were not supplied.
4. Screenshots are terminal-style images generated from source code and actual GCC output, not screenshots captured from VS Code.
